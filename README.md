## Open Source

### [code-review-agent](https://github.com/zaland2618/code-review-agent)

Paste in a source file and get back a plain-English code review — bugs, security issues and style problems flagged with real line numbers.

Runs against Groq's API or a fully offline local Ollama model. Files too large for a single request are split along genuine function and class boundaries — Python through the standard-library `ast` module, JavaScript and TypeScript through `tree-sitter` — so every finding still points at the correct line in the original file. Ships as both a CLI and a Streamlit web UI, with exponential-backoff retry handling on rate limits.

`Python` &nbsp;·&nbsp; `Groq` &nbsp;·&nbsp; `Ollama` &nbsp;·&nbsp; `tree-sitter` &nbsp;·&nbsp; `Streamlit`
