## About

Three years ago I joined Shurq, a UK SaaS platform for Amazon sellers, as a junior developer. I ended up the primary developer on the MVP and made senior while we built it. The dashboards are mine: live P&L reporting, ad manager grids, keyword rank tracking. They have to stay fast with a lot of seller data moving through them.

I also work with Croncore on AI products, where I built the frontend and the chatbot for a bilingual K–12 learning platform, plus their company site.

Nobody taught me this stack. I learned it by shipping to real users, and the products below are the evidence. I'm finishing a B.S. in Artificial Intelligence at Pak-Austria Fachhochschule (PAF-IAST) in 2026, and I'm open to remote work anywhere.

## Open Source

**[code-review-agent](https://github.com/zaland2618/code-review-agent)** — Paste in a file, get back a plain-English review with a real line number on every finding. It runs on Groq or fully offline on a local Ollama model. Files too big for one request get split along actual function and class boundaries instead of arbitrary line counts, so the findings still point at the right code.

`Python` `Groq` `Ollama` `tree-sitter` `Streamlit`
